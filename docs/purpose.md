# Purpose

pXv estimates water-surface velocity from downward-looking drone and
laboratory video. Particle tracking velocimetry (PTV) follows individual
tracers. Particle image velocimetry (PIV) estimates the motion of surface
texture across interrogation windows.

The browser app imports footage, georeferences vectors, compares speeds
with field observations, and exports figures and tables. The Python
workflow provides command-line processing, a desktop interface, and
GIS exports.
