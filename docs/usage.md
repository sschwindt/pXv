# Usage

For a first run, follow the [Isar River showcase](isar.md). The download
includes its video, camera information, and field measurements.

Once you have run the example, use the [browser app guide](browser.md) to
import your own footage, set the scale, check results against a field
survey, and export a figure or spreadsheet.
